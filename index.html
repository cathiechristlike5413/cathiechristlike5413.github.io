🔍 How Does Worktrunk Work?

Worktrunk uses a special Git feature called "worktrees." These are like parallel universes for your project - you can work on different tasks without them interfering with each other. It's perfect for:

  • Developing new features while keeping your main version stable
  • Running multiple AI agents to accomplish different tasks at once
  • Testing experimental changes without risk to your primary project
  • Collaborating with team members without conflicts

With Worktrunk, you don't need to understand all the technical details - just know that it keeps everything clean, organized, and safe.
